# Research outputs

Machine-generated research artifacts that support the chronology but are not part
of the published site.

- **`wayback-inventory.md`** — a human-readable index of what exists in the
  Internet Archive for `forodesaopaulo.org`, high-value pages (meeting
  declarations, member lists, history) first. Generated by
  [`scripts/wayback-harvest.js`](../scripts/wayback-harvest.js); the full
  machine-readable version is `data/wayback-inventory.json`.

These files are produced by the **Wayback collection** GitHub Action
([`.github/workflows/wayback.yml`](../.github/workflows/wayback.yml)), which runs
on GitHub's runners because some environments block `archive.org` by egress
policy. To generate locally (where the Internet Archive is reachable):

```bash
node scripts/wayback-harvest.js
```
