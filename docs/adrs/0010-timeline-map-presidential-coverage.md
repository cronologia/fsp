# ADR-0010: Timeline map of FSP presidential coverage ("pink tide")

- **Status:** Accepted
- **Date:** 2026-07-14

## Context

The country dossiers (ADR-0009) already encode, per country, which president in
each period came from an FSP member/affiliated party. Read one country at a time
that is hard to grasp; the interesting story is the **regional, year-by-year
pattern** — the geographic and temporal spread often called the "pink tide."
We wanted to surface that pattern without adding any runtime dependency
(ADR-0001), without introducing a charting library, and without overstating
what the data supports (ADR-0005: contested affiliations must not be asserted as
fact).

## Decision

Render a year-by-year heatmap on the home page (`#presidents-map`, nav "Pink
tide"), generated by `build.js` from `presidentialSuccession[]` — **no new
data.** Design points:

- **Layout:** a CSS grid, rows = tracked countries, columns = years 1990 →
  current. Each logical row is exactly one label cell + one cell per year (pure
  auto-flow, no explicit placement) so the year header, per-year tally bars, and
  country cells stay column-aligned. The grid scrolls inside its own
  `overflow-x:auto` container so the page body never scrolls horizontally on
  mobile.
- **Year-in-office rule:** for each year, the president is the one with the
  greatest `start ≤ year` whose term spans it (handles `"present"`, gaps, and
  handover years).
- **States, encoded by colour *and* fill** (WCAG 1.4.1, ADR-0005): solid =
  confirmed FSP, diagonal hatch = affiliation *to verify* (country `fspStatus`
  contains "verify"), solid light = non-FSP, outline = no data. _(Amended
  2026-07-14: a fifth state, a **cross-hatch for a one-party socialist state**,
  was added for Cuba — see below.)_
- **One-party states (Cuba):** a country flagged `oneParty: true` is
  FSP-governed but not by electoral alternation (the PCC has governed since
  1965). It is rendered as its own cross-hatched state, sorted to the bottom
  below the electoral rows, and **excluded from the per-year tally and the peak**
  so the electoral "pink tide" reading stays honest. The footnote names it.
- **Ordering:** rows sorted by the year each country first had an FSP president,
  so the wave reads as a diagonal.
- **Neutrality:** a per-year tally + peak callout state raw counts; the words
  "peak/wave/majority" are flagged as interpretive; to-verify affiliations are
  never counted as confirmed. A footnote states the map covers only the tracked
  countries, not all of Latin America.
- **Interaction (progressive enhancement, `src/app.js`):** hover/tap/focus a
  cell mirrors its detail into an `aria-live` caption; with JS off the `title`
  tooltips still work.

An **interactive map** (`#atlas`) sits at the very top: a real Latin America map
(actual country borders) recoloured by a **year slider** with a Play animation,
using the same states; neighbours are greyed for context. It **inlines a
committed SVG** (`src/latam.svg`) generated **once** from public-domain **Natural
Earth** 1:50m boundaries (via the npm `world-atlas` package, projected with
`d3-geo`) — see `scripts/gen-latam-svg.js`. That generator is **dev-only and not
part of the build**: `build.js` only inlines the committed SVG and injects the
per-year colours + hatch/cross-hatch patterns, so the **shipped site stays
zero-dependency and self-contained** (ADR-0001) with no external/fetched asset.
It server-renders the current year so a snapshot shows with JS disabled; `app.js`
adds the slider/animation, hover captions, and click-through to dossiers.

_(This replaced an earlier schematic tile-grid cartogram, once real
public-domain geometry could be obtained at generate-time without adding a
runtime or committed build dependency.)_

The same grid infrastructure also renders a **high-court interventions grid**
(`#courts-map`): per country per year, the documented court-packing / purge /
reform events from `supremeCourt.courtHistory[]`, encoded by colour and glyph
(P/×/R). Continuity is left blank; only interventions are marked, framed as a
record rather than a verdict.

All three visualizations sit at the **top of the home page**. The **interactive
map stands alone first** (the headline), followed by the two **year-by-year grids
(Presidential, Court interventions) in a tab interface** (ARIA tab pattern,
arrow-key navigation). Progressive enhancement: the tablist is hidden and the
grid panels simply stack until `app.js` activates the tabs, so with JS off
nothing is lost. Nav links that target a grid panel activate its tab.

A legislative/congress band is **deferred** to its own data + render tickets
(#106/#107) because it requires new sourced data.

## Consequences

- **Easier:** the regional pattern is visible at a glance and stays correct
  automatically — editing a country's succession or adding a country (ADR-0009)
  updates the map, the tally, and the peak with no map-specific work.
- **Easier:** the verified/to-verify distinction is visible, not buried in a
  flag, keeping the neutrality guarantee legible.
- **Neutral:** the map's honesty depends on `fsp` flags and `fspStatus` being
  set conservatively per ADR-0009; a mislabelled affiliation would show as a
  confident cell. The standing data-quality audit (#97) covers this.
- **Harder:** verified-vs-unverified is decided per *country* (`fspStatus`), not
  per president, so a country whose flagship party is confirmed but which also
  elected a different, unsourced left party needs care — that second president is
  left non-FSP rather than shown hatched. A per-president confidence flag would
  remove the compromise but is out of scope here.
